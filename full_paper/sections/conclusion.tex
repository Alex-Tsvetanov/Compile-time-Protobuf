\section{Conclusion}
In this paper, we presented \texttt{ctpb}, a header-only library for C++26 that performs Protocol Buffers serialization without external code generators. By uniting P1967 \texttt{\#embed}, \texttt{constexpr} recursive-descent parsing, and P2996 static reflection, \texttt{ctpb} compiles raw \texttt{.proto} schemas directly into type-safe, optimized C++ structures within the compiler front-end. Our empirical evaluation confirms sub-$11.4\,\mu\text{s}$ schema parsing latency, a $93.7\times$ reduction in standalone binary footprint, and runtime wire throughput reaching $1{,}396\,\text{MB/s}$ for serialization ($2.81\times$ speedup) and $350\,\text{MB/s}$ for deserialization ($1.71\times$ speedup) over Google's reference \texttt{libprotobuf}, a margin that holds against \texttt{libprotobuf-lite} as well.
