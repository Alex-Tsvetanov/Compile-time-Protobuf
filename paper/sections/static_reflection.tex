\section{Static Reflection and Type Generation}

\subsection{P2996 Reflection Pipeline}
Once the AST is parsed, \texttt{ctpb} maps the schema onto a native aggregate using \texttt{std::meta::info} reflection tokens and compile-time member descriptors. This is the step that replaces \texttt{protoc}: the struct is not written to disk and re-read, but constructed directly in the translation unit.

\begin{lstlisting}[language=ModernC++, caption={Programmatic Struct Member Injection}]
template <fixed_string ProtoSource, fixed_string MessageName>
consteval auto complete_message_struct(std::meta::info incomplete_type) {
    using Schema = parse<ProtoSource, MessageName>;
    constexpr auto count = Schema::field_count();
    std::vector<std::meta::info> members;

    auto append_member = [&]<std::size_t I>() {
        constexpr auto info = Schema::get_field(I);
        std::meta::info type_info = resolve_type_info(info.type);
        if (info.is_repeated) {
            type_info = std::meta::substitute(^^std::vector, {type_info});
        }
        members.push_back(std::meta::data_member_spec(
            type_info, {.name = info.name}
        ));
    };

    [&]<std::size_t... Is>(std::index_sequence<Is...>) {
        (append_member.template operator()<Is>(), ...);
    }(std::make_index_sequence<count>{});

    return std::meta::define_aggregate(incomplete_type, members);
}
\end{lstlisting}

\subsection{Type Mapping and Generated Interface}
The proto3-to-C++ mapping is strict and deterministic: the sized integer types map to the corresponding \texttt{std::int$N$\_t} and \texttt{std::uint$N$\_t} (with \texttt{sint} and \texttt{sfixed} variants sharing the signed representation and differing only in wire encoding), \texttt{float}/\texttt{double}/\texttt{bool} map to their C++ equivalents, \texttt{string} to \texttt{std::string}, \texttt{bytes} to \texttt{std::vector<std::byte>}, \texttt{repeated T} to \texttt{std::vector<T>}, \texttt{map<K,V>} to \texttt{std::unordered\_map<K,V>}, and \texttt{oneof} to \texttt{std::variant}.

Beyond member generation, \texttt{ctpb} supplies direct dot-syntax field access (\texttt{p.name}), non-intrusive \texttt{ctpb::encode} and \texttt{ctpb::decode} visitors that traverse the member descriptors reflectively, and defaulted member-wise comparison operators.
