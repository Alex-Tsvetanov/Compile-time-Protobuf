\begin{abstract}
Serialization frameworks such as Protocol Buffers typically rely on external code generators (\texttt{protoc}) to translate schemas into C++ files, which adds build rules, version coupling, and generated source. This paper presents \texttt{ctpb}, a header-only C++26 library that uses static reflection to parse \texttt{.proto} schemas and synthesize C++ types during compilation. The library carries the schema in the translation unit as a compile-time string, performs a \texttt{constexpr} recursive-descent parse into an Abstract Syntax Tree, and materializes type-safe fields and wire-format visitors without generated \texttt{.pb.h} or \texttt{.pb.cc} files. On one host, a synthetic 100-field schema is parsed in $7.239\,\mu\text{s}$ (range $7.227$ to $7.256\,\mu\text{s}$). For a 47-byte, three-field \texttt{Person} workload, \texttt{ctpb} encodes between $5.38\times$ and $5.59\times$ faster than full and lite \texttt{libprotobuf}, while decoding remains near parity (between $1.09\times$ and $1.10\times$) and includes proto3 UTF-8 validation. A stripped sample executable is $18{,}776$ bytes versus $1{,}759{,}368$ bytes for the generated-code static-runtime comparison. Wire-format fidelity is verified bidirectionally against the reference implementation.
\end{abstract}
