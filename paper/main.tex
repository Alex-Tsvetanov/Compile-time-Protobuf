\begin{abstract}
Serialization frameworks like Protocol Buffers rely on external code generators (\texttt{protoc}) to translate schema definitions into intermediate C++ header and implementation files, introducing build-system complexity, toolchain version skew, and substantial compilation bloat. In this paper, we present \texttt{ctpb}, a modern header-only C++26 library that eliminates external code generation entirely by performing compile-time IDL parsing and type synthesis using C++26 static reflection (P2996) and resource inclusion (P1967 \texttt{\#embed}). We design a three-stage compile-time pipeline where \texttt{.proto} schemas are tokenized and parsed into a lightweight Abstract Syntax Tree during constant evaluation, and subsequently materialized into first-class C++ structs with optimized wire serialization visitors. Benchmarks demonstrate compile-time schema parsing latencies under $55\,\mu\text{s}$ per message, and runtime wire throughput of $1{,}629.6\,\text{MB/s}$ for serialization and $775.2\,\text{MB/s}$ for deserialization, a $2.21\times$ and $2.26\times$ speedup respectively over Google's official \texttt{libprotobuf}, verified through bidirectional wire-format interoperability testing against the reference implementation. Our findings show that static reflection provides an optimal, zero-overhead foundation for native IDL compilation in systems programming.
\end{abstract}
